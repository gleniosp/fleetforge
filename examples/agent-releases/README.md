# Agent release examples

[Version 1 conformance fixtures](conformance/v1/README.md) contain illustrative
agent artifact and activation metadata for Linux AMD64 and ARM64, with fixed
canonical bytes, digests and signatures. They contain no installable environment.

The [agent release walkthrough](../../docs/guides/agent-releases-explained.md)
explains how to read the examples and which checks need more than a schema.
The [specification](../../docs/specs/agent-releases.md) owns exact format rules;
[agent delivery](../../docs/architecture/agent-delivery.md) owns the intended
installation and recovery lifecycle.
