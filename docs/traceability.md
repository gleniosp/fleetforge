# Requirement traceability

This map links expected behavior to delivery owners and intended verification.
It does not assert that the listed components or tests already exist. Read the
[requirements](product/requirements.md) for product contracts and the
[architecture](architecture/overview.md) for boundaries. GitHub issues own live
implementation/checklist/review state; journal and CI links provide actual evidence.
